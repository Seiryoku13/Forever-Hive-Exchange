# Changelog

## 0.1.1 • November 21, 2026

- Match recent official hotfix notes to screened items by item name. Open a matched change directly from the price history window.
- Upgrade existing databases transactionally and preserve prior observations, trades and settings. Refuse a database created by a newer unsupported schema.
- Verify the standard per-user installation, installed executable hash and Start menu shortcut on the Windows release runner.

## 0.1.0 • November 21, 2026

- First Windows release of Forever Hive Exchange with SQLite history, a native desktop GUI and a per-user or portable installer.
- Added local Auctionator, TSM, Mastercraft and Forever Hive Command adapters and an hourly public market provider.
- Added pricing and break-even calculations, historical charts, flip and investment screens, recipe margins, a cost-basis portfolio and threshold notifications.
- Added Blizzard news and hotfix monitoring, dated raid and item-change context, and explicit source health.
- Added tray monitoring, optional Windows sign-in startup, release checks and opt-in SHA-256-verified updates.
